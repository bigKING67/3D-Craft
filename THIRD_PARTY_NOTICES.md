# Third-party notices

3D-Craft V0.1 selectively absorbs workflow ideas, not source snapshots, from
the upstream projects recorded in `upstreams.lock.json`. No third-party model,
image, texture, or copied source file is distributed in the initial candidate.

Runtime dependencies retain their own licenses in the installed npm dependency
tree. Notable dependencies include React, Three.js, React Three Fiber, Drei,
Vite, and Khronos glTF Validator.

Before copying upstream code or assets in a future change, add its exact source
path, commit, license, local destination, and required notice here.
